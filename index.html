Hanyang LMS Whisper

한양대 LMS 강의 탭의 오디오를 브라우저 안에서 Whisper로 전사합니다.
사용 순서
① Chrome/Whale에서 LMS 강의를 열어 둡니다.
② 이 페이지에서 Start를 누릅니다.
③ 공유 창에서 Chrome 탭 / Whale 탭 → LMS 강의 탭을 선택합니다.
④ ‘탭 오디오 공유’가 보이면 켭니다. 최신 Chromium에서는 별도 체크 없이 자동 포함될 수도 있습니다.
⑤ 강의가 끝나면 Stop → Download TXT.
Whisper 엔진 준비 전
Start를 누르면 모델을 준비합니다.
약 35초 단위로 오디오를 처리합니다. 첫 전사는 모델 준비 후 약 35초 뒤 나타납니다.
No STT API Browser-side Whisper
음성 데이터는 별도의 음성인식 서버로 업로드하지 않습니다. 최초 사용 시 Whisper 모델과 실행 라이브러리를 인터넷에서 내려받으며, 이후에는 브라우저 캐시가 재사용될 수 있습니다.
